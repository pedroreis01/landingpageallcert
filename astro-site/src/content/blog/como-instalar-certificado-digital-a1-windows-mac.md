Recebeu seu certificado **A1** da AllCert? Lembrando sempre: o **certificado A1 é um arquivo para ser instalado no computador**. Veja o passo a passo simplificado para instalar no Windows ou Mac.

## Passo a Passo para Windows (10 e 11)

1. Localize o arquivo baixado (geralmente com extensão `.pfx` ou `.p12`).
2. Dê um duplo clique no arquivo para abrir o *Assistente de Importação de Certificados*.
3. Selecione a opção **Usuário Atual** ou **Máquina Local** (se desejar liberar para todos os usuários).
4. Insira a **senha do certificado** criada no momento da emissão.
5. Marcar a opção *"Marcar esta chave como exportável"* para garantir backup futuro.
6. Clique em **Avançar** e depois em **Concluir**.

## Passo a Passo para macOS

1. Abra o arquivo `.pfx` baixado.
2. O aplicativo **Acesso às Chaves (Keychain Access)** será aberto automaticamente.
3. Digite a senha do certificado e confirme a importação no repositório *Login*.
